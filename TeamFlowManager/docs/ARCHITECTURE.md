## 💾 数据层架构详解

### 3.1 Repository 模式 + 乐观更新 🔥

#### 设计原则：「先更新 UI，后写入数据库」

```typescript
// ✅ 现在的模式
async updateTask(id: number, updates: Partial<Task>) {
  await tasksRepo.update(id, updates)   // 1. 写入数据库（异步）
  this.list = this.list.map(t =>    // 2. 本地原子更新（同步）
    t.id === id ? { ...t, ...updates } : t
  )
}

// ❌ 旧的模式
async updateTask() {
  await tasksRepo.update(...)
  await this.fetchTasks()  // O(N) 全表重查，浪费！
}
```

**性能提升：O(N) → O(1)，列表越大提升越明显！

### 3.2 Dexie 数据安全序列化机制

```typescript
// 解决 Vue 响应式对象无法克隆的问题
function toPlainObject<T>(obj: T): T {
  return JSON.parse(JSON.stringify(obj))
}

// 兜底异常降级策略
function safeSerialize<T>(obj: T): T {
  try {
    return toPlainObject(obj)
  } catch (e) {
    return { ...obj } as T  // 降级方案
  }
}
```

### 3.3 数据层错误处理

| 操作 | 失败降级 | 异常 |
|------|--------|------|
| getAll() | 返回空数组 | 不崩溃 |
| getById() | 返回 undefined | 优雅降级 |
| create/update/delete | 抛出异常 | 上层 catch |

## ✅ 表单安全机制

### 4.1 防重复提交三重保障

```
提交按钮点击
    │
    ▼
  submitting = true ────┐
    │                │ 锁定
    ▼                │
Loading 按钮状态        │
    │                │
    ▼                │
finally 解锁          │
    │                │
    ▼                │
  submitting = false ◀───┘
```
