## 💡 贡献指南

### 开发工作流

1. **Pick 任务**：从上面列表选择高优先级任务
2. **创建分支**：`feature/任务名称` 或 `fix/问题描述`
3. **开发验证**：确保 `npm run typecheck && npm run lint` 通过
4. **提交 PR**：关联对应里程碑

### 提交规范

```
feat: 新增项目编辑功能
fix: 修复登录跳转时序问题
refactor: 提取 useAsync composable
docs: 更新路线图文档
```

### 质量门禁

每笔提交必须通过：
- ✅ TypeScript 类型检查无错误
- ✅ ESLint 无错误
- ✅ 生产构建成功
