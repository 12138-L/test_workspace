## 📋 项目介绍

### 1.1 产品定位

**TeamFlow Manager** 是一款面向团队管理者的**本地优先、离线可用、数据封闭安全**的团队管理 PWA 工具。

> 「把分散在文件夹、Excel、邮件中的团队管理工作，结构化、自动化、智能化」

### 1.2 核心价值

| 价值点 | 说明 |
|--------|------|
| 🔒 **数据绝对安全** | 100% 存储于本地浏览器 IndexedDB，不上传任何服务器 |
| ✈️ **离线优先设计** | PWA 安装后完全离线可用，无网络依赖 |
| 📦 **开箱即用** | 纯前端应用，下载后打开即用，无需部署后端 |
| 🤖 **AI 可选增强** | 提供离线 OCR、智能分类、自然语言查询等能力 |
| 🔐 **设备启用控制** | 指纹校验 + AES 加密备份，多设备安全同步 |

### 1.3 目标用户与场景

**主要用户**：团队管理者、小组长、HR 专员、行政人员

**典型使用场景：**
- 团队成员档案与证件管理
- 请假/加班/调休记录跟踪
- 法定节假日与综合工时自动计算
- Excel 考勤数据自动汇总归档
- 绩效与结算报表一键生成
- 发票智能识别与分类整理
- 个人待办任务与农历周期提醒

## 💡 设计理念

### 2.1 架构设计原则

#### 🎯 **原则 1：本地优先 (Local-First)**

> 「网络是可选的，数据是你的」

- 所有读写操作优先走本地 IndexedDB
- 同步是可选的高级功能
- 断网不影响核心功能使用
- 用户拥有数据的完全控制权

#### 🎯 **原则 2：渐进式复杂度**

> 「简单的事情简单做，复杂的事情可选择」

| 用户层级 | 功能范围 | 学习成本 |
|---------|---------|---------|
| 入门用户 | 基础 CRUD 操作 | 5 分钟上手 |
| 进阶用户 | 批量导入、报表生成 | 30 分钟精通 |
| 高级用户 | AI 增强、加密备份 | 按需启用 |

**设计体现：**
- AI 模块默认关闭，手动开启后才加载（减少包体积）
- 高级功能在「设置」中统一开关
- 核心路径操作不超过 3 次点击

#### 🎯 **原则 3：性能预算**

> 「每一行代码都要为性能负责」

| 指标 | 预算值 |
|------|--------|
| 首屏加载 | < 2 秒 |
| 页面切换 | < 200ms |
| 列表渲染（1000 条）| < 500ms |
| 文件处理 | Web Worker 不阻塞 UI |
| 包体积 | 核心功能 < 2MB，AI 模块懒加载 |

#### 🎯 **原则 4：Type-First 开发**

> 「类型是最好的文档，也是最好的测试」

- 所有 API 100% TypeScript 类型覆盖
- Store 状态强类型定义
- 运行时数据校验（Zod）
- 自动生成类型导出

---

### 2.2 技术选型思考

**为什么选 Vue 3 + Pinia？**
- Composition API 组合式逻辑复用更灵活
- Pinia 比 Vuex 更轻量，更好的 TypeScript 支持
- 生态成熟，Element Plus 组件库完善

**为什么不用 Electron？**
- PWA 安装体积 < 5MB vs Electron > 100MB
- PWA 自动静默更新
- 浏览器沙箱天然安全
- 跨平台一致性更好

**为什么不用后端？**
- 90% 的团队管理场景不需要多用户协作
- 本地数据库足够支持 10 万条记录
- 用户数据隐私是最高优先级
- 降低部署和维护成本
